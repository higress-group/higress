# 招标信息查询

一个用于查询**中国招标公告与中标结果**的 MCP 服务器，由 Higress 托管。将它接入你的 AI 助手（Claude、Cursor、Cherry Studio 等）后，即可用自然语言搜索全国招标信息、分析竞争对手中标情况。

数据覆盖全国各省市的招标与中标信息，实时更新。

## 能做什么

- 🔍 **搜索招标公告**：按关键词、日期范围、省市区筛选招标公告
- 🏆 **搜索中标结果**：查询中标/成交结果，支持按中标公司名称过滤
- 📄 **获取公告详情**：查看单条公告的完整内容

## 可用工具

### 1. `search_bid_notices` — 搜索招标公告

根据关键词搜索招标公告，支持按日期、地区过滤。

| 参数           | 类型   | 必填 | 说明                                   |
| -------------- | ------ | ---- | -------------------------------------- |
| `keyword`    | string | ✅   | 搜索关键词                             |
| `start_date` | string |      | 开始日期（格式`YYYY-MM-DD`）         |
| `end_date`   | string |      | 结束日期（格式`YYYY-MM-DD`）         |
| `province`   | string |      | 项目所在省份（中文全称，如`广东省`） |
| `city`       | string |      | 项目所在城市（中文全称，如`深圳市`） |
| `page`       | int    |      | 页码，从 1 开始（默认 1）              |
| `page_size`  | int    |      | 每页条数（默认 20，最大 100）          |

### 2. `search_bid_results` — 搜索中标结果

查询中标/成交结果，在招标公告参数基础上额外支持按中标公司过滤。

| 参数                          | 类型   | 必填 | 说明                       |
| ----------------------------- | ------ | ---- | -------------------------- |
| `keyword`                   | string | ✅   | 搜索关键词                 |
| `company_name`              | string |      | 中标公司名称过滤           |
| `start_date` / `end_date` | string |      | 日期范围（`YYYY-MM-DD`） |
| `province` / `city`       | string |      | 项目所在地区（中文全称）   |
| `page` / `page_size`      | int    |      | 分页参数                   |

### 3. `get_bid_detail` — 获取公告详情

根据文档 ID 获取单条公告的完整内容（正文已去除 HTML 标签）。

| 参数           | 类型   | 必填 | 说明                                            |
| -------------- | ------ | ---- | ----------------------------------------------- |
| `doc_id`     | string | ✅   | 文档 ID（来自搜索结果的`id` 字段）            |
| `index_type` | string | ✅   | `notice`（招标公告）或 `result`（中标结果） |

## 使用示例

接入后，你可以直接用自然语言向 AI 助手提问：

**搜索招标信息：**

> 帮我搜索最近一个月广东省关于"智慧城市"的招标公告

> 查一下北京市 2026 年以来的信息化建设招标项目

**分析竞争对手：**

> 分析华为技术有限公司今年的中标情况，主要中标了哪些项目？

> 看看"中科软"在医疗行业中标了哪些项目

**查看详情：**

> 把刚才第一条招标公告的完整内容展示给我

**推荐的查询思路：**

1. 先用 `search_bid_notices` 搜索招标公告，了解市场上有哪些项目在招标
2. 再用 `search_bid_results` 查看中标结果，了解竞争格局
3. 对感兴趣的公告用 `get_bid_detail` 获取完整详情

## 使用限制

为保证服务稳定，对接入方做如下限制：

- **请求频率**：默认每个 IP 每日最多 **50 次**请求，超出后会返回限流提示
- **分页限制**：单次查询最多返回 100 条，深度分页有限制，建议用更精确的关键词缩小范围

如有更高的用量需求，请联系服务管理员。

## 常见问题

**Q：连接失败怎么办？**
A：请检查：① URL 是否正确；② 网络是否能访问该地址。

**Q：提示"限流"怎么办？**
A：默认每个 IP 每日 50 次请求。请减少请求频率，或联系管理员提升额度。

**Q：搜索没有结果？**
A：尝试：① 换更宽泛的关键词；② 去掉日期或地区过滤；③ 确认省份/城市使用中文全称（如"广东省"而非"广东"）。

**Q：日期格式要求？**
A：统一使用 `YYYY-MM-DD` 格式，例如 `2026-09-01`。
